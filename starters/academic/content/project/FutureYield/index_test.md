# The Future Yield Challenge

<div style="font-size: 0.9em; text-align: justify;">

**Summary:**  
Predict end-of-season wheat and maize yields for each grid cell and year using daily weather data from the growing season and preceding days, along with soil texture and ambient CO₂ levels. The challenge involves predicting future yields (2021–2100) under a high-emissions climate scenario, using training data from 1980–2020.

Modeling is performed using Python and TensorFlow, with methods including Random Forests, Feedforward Neural Networks, and Long Short-Term Memory (LSTM) networks.
